# 2.1 Introduction

This prototype presents the NB Connect Customer-to-Customer (C2C) e-commerce platform designed to facilitate secure online transactions between individual buyers and sellers in South Africa. The platform addresses the challenges faced by informal traders by providing a centralized digital marketplace with real-time inventory visibility, secure payment processing, and comprehensive user management. Built using HTML, CSS, JavaScript, PHP, and MySQL with Bootstrap for responsive design, the system includes a customer-facing website for browsing, purchasing, and selling goods, alongside an administrative panel with Role-Based Access Control (RBAC) for managing users, products, orders, and system analytics. The design follows the CRISP-DM methodology to ensure structured data handling and analytical capability, supporting the transition from manual, fragmented processes to a scalable, professional digital solution.
